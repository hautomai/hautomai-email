# Security

This repository is a public, sanitized copy of an internal project. Credentials,
customer records and generated documents are **not** published and must never be
committed.

## Reporting a vulnerability

If you believe you have found a security issue, please **do not open a public
issue**. Report it privately through GitHub's
[private vulnerability reporting](../../security/advisories/new) or by contacting
the maintainers. We aim to respond within 5 business days.

## Secrets in history

If you find a credential in this repository, treat it as compromised and report
it immediately so it can be rotated and removed.
